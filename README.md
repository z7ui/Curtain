# 幕布 (Curtain)
模仿三星幕布、游戏助推器触控保护功能
一款用纯黑悬浮窗覆盖屏幕的 Android 应用，适合 OLED 屏幕省电、防止游戏更新时锁屏。

## 功能
- 全黑悬浮窗覆盖，OLED 像素点不发光
- 保持屏幕常亮，不锁屏
- 保持后面应用前台运行
- 控制中心磁贴一键开关
- 时间 / 日期 / 电量显示
- 亮度级别 1-5（渐变遮罩）
- 自动息屏 15 秒 ~ 从不，共 8 档
- 拖动中央图标下滑解锁

## 使用
1. 安装 APK
2. 授予「显示在其他应用上层」权限
3. 下拉控制中心，把「幕布」磁贴拖出来
4. 点击磁贴启动

| :--- | :---: | :---: | :--- | :--- |
| 三星原生 | ✅ 可以 | ✅ 可以 | 系统签名权限 | 三星游戏助推器 |
| 无障碍悬浮窗 | ❌ 不能 | ✅ 可以 | 无障碍服务 | FakeStandby |
| Shizuku 方案 | ✅ 可以 | ✅ 可以 | Shizuku (ADB) | Duos, Extinguish |
| Xposed 模块 | ✅ 可以 | ✅ 可以 | Root + LSPosed | Castix |
| 沉浸模式 Activity | ✅ 可以 (隐藏) | ❌ 会切换前台 | 无 | Immersive Mode Manager |


### 说明

- **三星原生**：依赖系统签名权限 `INTERNAL_SYSTEM_WINDOW`，普通应用拿不到
- **无障碍悬浮窗**：兼容性好，无需 Root，但状态栏无法覆盖
- **Shizuku 方案**：非 Root 环境下唯一能覆盖状态栏的途径，需要用户通过 ADB 激活 Shizuku
- **Xposed 模块**：功能最彻底，需要 Root + LSPosed，门槛最高
- **沉浸模式 Activity**：无需权限，但会切换前台应用，无法保持后台应用运行
